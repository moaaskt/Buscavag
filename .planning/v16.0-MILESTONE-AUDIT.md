## 2. Cross-Phase Integration Check

- **Fase 61 → Fase 62 (Coleta → Extração de Contatos)**: O conteúdo extraído de forma furtiva pelo scraper de feed é repassado ao parser semântico e regex de fallback para garantia da extração do contato direto.
- **Fase 62 → Fase 63 (Extração → Persistência)**: As vagas com e-mail direto e detalhes inferidos são processadas pelo gerador de hash `generateJobHash`, que detecta a plataforma `LINKEDIN_POSTS` e utiliza a URN extraída para criar um hash imutável e à prova de pequenas variações de texto. As vagas são então salvas de forma segura no SQLite.
- **Fase 63 → Fase 64 (Persistência → Experiência)**: A UI recupera os registros de vagas do tipo "LinkedIn Feed", e exibe o crachá específico da plataforma. A UI dá o devido destaque ao canal direto (e-mail) extraído pelo pipeline semântico.

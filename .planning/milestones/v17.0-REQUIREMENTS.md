# Requirements: Milestone 17.0

## Epic
**Motor de Match Estrito, Onboarding Sequencial & Refatoração da Inbox do Candidato**
Tornar o ecossistema do candidato 100% fiel às suas preferências reais, implementando filtros eliminatórios de senioridade no motor de match, exigindo onboarding sequencial (upload de CV + análise de IA antes do feed de recomendadas) e ajustando as regras de ingestão e fluxo na Inbox do Kanban.

## User Stories
1. [x] Como candidato, quero que o algoritmo de match bloqueie rigorosamente vagas com senioridades incompatíveis com meu perfil (ex: Júnior aplicado a vaga Sênior) para evitar perdas de tempo.
2. [x] Como candidato, quero que meu modelo de trabalho (Remoto/Híbrido) e pretensão salarial tenham um peso forte e direto no percentual de match.
3. [x] Como sistema, quero travar a aba "Vagas Recomendadas" caso o candidato não tenha finalizado a extração do CV e a definição de perfil via IA.
4. [x] Como sistema, quero extrair e alinhar a biografia do CV com a senioridade real declarada, evitando distorções.
5. [x] Como candidato, quero que as vagas recém-coletadas caiam diretamente na minha Inbox com ordenação por aderência para facilitar minha tomada de decisão.
6. [x] Como candidato, quero que vagas categoricamente incompatíveis sejam descartadas do banco para manter minha inbox qualificada.

## Requirements
- [x] `REQ-01`: Refatorar `CandidateMatcher` e `hermesEvaluator` para impor hard constraints (penalizações severas) baseadas em senioridade divergente (teto eliminatório cravado em 35%).
- [x] `REQ-02`: Aumentar peso no cálculo de match para localidade/modelo de trabalho e pretensão salarial via `parseSalary`.
- [x] `REQ-03`: Restringir avaliação semântica de Stack a vagas que já passaram nas regras de exclusão base, isolando a pontuação.
- [x] `REQ-04`: Implementar Lock Screen orientativa na rota de recomendações, bloqueando o acesso até a conclusão do upload/extração do CV (`onboarding_completed`).
- [x] `REQ-05`: Ajustar prompt de extração do CV no Scrapling Engine (`cv_analyzer.py`) para categorizar `primary_stack`, `secondary_stack`, `work_model` e `expected_salary`.
- [x] `REQ-06`: Sincronizar o formulário de Perfil Profissional automaticamente com o parsing de CV finalizado via `/api/candidate/sync-skills`.
- [x] `REQ-07`: Adicionar barreira eliminatória na borda de ingestão do scraper (`src/index.ts`) para descartar vagas com `overallScore <= 35%`.
- [x] `REQ-08`: Ordenar vagas salvas na Inbox e Kanban por `j.overall_score DESC, s.created_at DESC` e exibir badge de `Super Match` com realce esmeralda quando score >= 75%.

# Milestone 20.0: Resiliência Geográfica, Tratamento de Localizações Omissas & Tolerância de Payloads

Iniciado em: 2026-09-23  
Status: Concluído em 2026-09-23  
Conclusão: 100% dos requisitos entregues (REQ-01 a REQ-06)

## Visão Geral
Refinar a inteligência de compatibilidade geográfica e a camada de API do BuscaVag, solucionando os apontamentos catalogados no backlog técnico (W-01.1, W-01.2 e I-06). A plataforma elimina falsos-positivos de Hard Block em vagas presenciais que trazem apenas a cidade sem a UF ou que possuem localização não informada, e introduz resiliência robusta na API de perfil para aceitar formulários com campos opcionais vazios e sanitização de texto via `.trim()`.

## Estrutura de Fases

### Phase 74: Refinamento de Matching Geográfico (Cidades sem UF & Localizações Omissas)
- Tratamento de vagas presenciais/híbridas com campo `location` nulo, vazio ou genérico (`"Não informado"`, `"A combinar"`), retornando avaliação neutra (`locationScore: 70`, `locationCap: 100`, `isGeoHardBlocked: false`).
- Match municipal perfeito (score 100, sem teto) para vagas com cidades sem UF explícita (ex.: `"Florianópolis"`, `"Curitiba"`, `"São Paulo"`), com proteção anti-colisão de prefixos ("Rio" vs "Rio Grande do Sul") e verificação de não-conflito de UFs.
- Preservação estrita do Hard Block eliminatório de 35% para vagas presenciais em estados divergentes.
- Suíte `src/test-phase74.ts` com 13 asserções automatizadas aprovadas (13/13).

### Phase 75: Resiliência de Payload e Sanitização na API de Perfil
- Flexibilização do `profileSchema` com `z.preprocess()` para normalizar `state: ""` ou strings com apenas espaços para `null`, evitando erros HTTP 400 (`Invalid enum value`) e mantendo a validação das 27 UFs válidas brasileiras (`VALID_UFS`).
- Sanitização sistemática com `.transform((v) => v?.trim() || null)` em todos os campos de texto opcionais (`target_role`, `seniority`, `expected_salary`, `bio`, `city`), garantindo dados consistentes e limpos no SQLite.
- Exportação de schemas e constantes para fortes garantias de tipagem.
- Suíte `src/test-phase75.ts` com 10 asserções automatizadas aprovadas (10/10).

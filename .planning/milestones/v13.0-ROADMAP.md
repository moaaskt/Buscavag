# Milestone 13: Experiência de Autenticação (/login, /register), Header Minimalista & Notificações WhatsApp

## Overview
Implementa paridade total entre Light e Dark Mode nas páginas de autenticação com cards glassmórficos modernos, isola o fluxo de auth com cabeçalho minimalista que suprime navegação interna e barra flutuante mobile, erradica 100% dos SVGs manuais com padronização completa na biblioteca `lucide-react`, e desenvolve o subsistema de mensageria móvel via WhatsApp (Evolution API / Webhook HTTP) com sintetizador de cartas de apresentação (pitch) para candidatos.

## Phases

### Phase 49: Redesign Responsivo de Auth (/login & /register)
- Eliminação de containers rígidos escuros (`bg-zinc-950`) e tags `<main>` duplicadas.
- Cards glassmórficos adaptativos (`bg-white/85 dark:bg-zinc-900/70 border border-zinc-200 dark:border-zinc-800/80 shadow-xl dark:shadow-2xl`).
- Inputs com alto contraste, labels mono, alertas refinados e botões primários destacados em esmeralda.

### Phase 50: Header Minimalista em Rotas de Autenticação
- Detecção dinâmica de rotas `/login` e `/register` via `usePathname()`.
- Supressão de links internos, menus de navegação e botões duplicados no desktop e mobile.
- Posicionamento do alternador de tema Claro/Escuro no cabeçalho superior mobile.
- Ocultação da barra inferior flutuante (`FloatingDockMobile`) durante o fluxo de autenticação.

### Phase 51: Padronização Completa de Ícones (lucide-react)
- Erradicação de 100% dos SVGs manuais inline (`flash-icon.tsx` e `loader.tsx` excluídos).
- Adoção de `<RefreshCw className="animate-spin ..." />` no botão de atualização da Dashboard.
- Adoção de `<Loader2 className="animate-spin" />` para spinners do Painel Administrativo.
- Diferenciação semântica do item "Painel Admin" na Navbar com o ícone `<ShieldCheck />`.

### Phase 52: Engine de Notificações WhatsApp (Webhook Genérico / Evolution API)
- Conector de mensageria em `src/services/whatsappService.ts` com suporte para Evolution API, Webhooks HTTP e modo Mock automático.
- Formatação rica em Markdown do WhatsApp para alertas de vagas com Match IA >= 80%.
- Sintetizador de cartas de apresentação (Pitch/Cover Letter) para abordagem profissional a recrutadores.
- Rota de API `/api/notifications/whatsapp` para status, testes, envio de alertas e prévias.
- Integração no `JobModal.tsx` com botões "Copiar Carta" e "WhatsApp".

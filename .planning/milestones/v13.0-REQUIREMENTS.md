# Milestone 13: Experiência de Autenticação (/login, /register), Header Minimalista & Notificações WhatsApp

## Overview
Garante experiência moderna de autenticação responsiva em Light e Dark Mode, isola a navegação durante login/registro, padroniza 100% dos ícones em `lucide-react` e implementa canal de mensageria WhatsApp com gerador de cartas de apresentação.

---

## Requisitos Funcionais

### 1. Background Responsivo & Design System de Auth (/login e /register)
- [x] **REQ-1301**: Páginas `/login` e `/register` sem containers fixos `bg-zinc-950`, integradas ao `<AuroraBackground>` do layout.
- [x] **REQ-1302**: Cards glassmórficos adaptativos com alto contraste em Light Mode e Dark Mode.
- [x] **REQ-1303**: Inputs, botões de ação e alertas visuais padronizados com o design system do Buscavag.

### 2. Header Minimalista em Rotas de Autenticação
- [x] **REQ-1304**: Detecção de rotas de auth via `usePathname()` no componente `Navbar.tsx`.
- [x] **REQ-1305**: Ocultação de links internos do candidato/admin nas páginas `/login` e `/register`.
- [x] **REQ-1306**: Exibição focada da Logo do Buscavag e do alternador de tema Claro/Escuro.
- [x] **REQ-1307**: Supressão do dock flutuante móvel (`FloatingDockMobile`) durante o fluxo de autenticação.

### 3. Padronização Completa de Ícones (lucide-react)
- [x] **REQ-1308**: Remoção de 100% dos SVGs inline e ad-hoc em componentes da aplicação.
- [x] **REQ-1309**: Botão "Atualizar" na Dashboard utiliza `<RefreshCw className="animate-spin ..." />`.
- [x] **REQ-1310**: Painel Administrativo adota `<Loader2 className="animate-spin" />` de `lucide-react`.
- [x] **REQ-1311**: Painel Admin na Navbar adota `<ShieldCheck />` para evitar ambiguidade com `<LayoutDashboard />`.

### 4. Engine de Notificações WhatsApp (Webhook Genérico / Evolution API)
- [x] **REQ-1312**: Serviço desacoplado em `src/services/whatsappService.ts` compatível com Evolution API e Webhook HTTP.
- [x] **REQ-1313**: Suporte a modo Mock com logs estruturados para desenvolvimento local sem credenciais externas.
- [x] **REQ-1314**: Disparo automático de alertas para vagas com pontuação de Match IA >= 80%.
- [x] **REQ-1315**: Sintetizador de cartas de apresentação (Pitch/Cover Letter) personalizadas para abordagem a recrutadores.
- [x] **REQ-1316**: Rota de API `/api/notifications/whatsapp` com endpoints GET e POST para status, testes e prévias.
- [x] **REQ-1317**: Botões de ação rápida no `JobModal.tsx` ("Copiar Carta" e "WhatsApp").

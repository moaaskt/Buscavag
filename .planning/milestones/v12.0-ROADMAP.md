# Milestone 12: Polimento UI/UX, Total Multi-tenancy, Scraper Stream & Zero-State DB

## Overview
Consolida o isolamento multi-tenant absoluto no Kanban de candidaturas, estabelece trava de paywall e upsell para contas Free na análise de currículo por IA, sincroniza resumos executivos diretamente para a bio do candidato e garante resiliência em banco de dados zero-state, além de otimizar streams de logs dos scrapers e paridade visual de temas.

## Phases

### Phase 45: Kanban Isolamento Multi-tenant
- Endpoint `/api/candidate/board` isolado por candidato (`userId`), consultando exclusivamente `user_saved_jobs`.
- Endpoint `/api/candidate/board/status` para persistência direta de drag-and-drop de candidaturas.
- Inicialização do Kanban em zero-state para novos usuários.

### Phase 46: Paywall Free na Análise de CV
- Interceptação com `HTTP 403 Forbidden` em `/api/candidate/analyze-cv` para usuários Free com análise prévia.
- Botão "Upgrade Pro para Reanalisar" e redirecionamento de upsell na UI.

### Phase 47: Sincronização do Resumo para Bio
- Schema Zod em `/api/candidate/sync-skills` estendido para suportar `summary`.
- Atualização em `CandidateRepository.syncSkillsToProfile` para gravar na coluna `bio`.
- Sincronização instantânea na interface de perfil do candidato.

### Phase 48: Polimento de UI, Scraper Stream & Zero-State DB
- Criação do utilitário `scripts/reset-db.cjs` para reinicialização segura de bancos de dados zero-state.
- Definição de `PYTHONUNBUFFERED: '1'` para streaming em tempo real de logs dos scrapers via SSE.
- Padronização visual e polimento de temas claro e escuro no design system.

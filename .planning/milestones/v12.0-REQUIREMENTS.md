# Milestone 12: Polimento UI/UX, Total Multi-tenancy, Scraper Stream & Zero-State DB

## Overview
Garante o isolamento multi-tenant completo no gerenciamento de vagas salvas, estabelece travas de monetização B2C com IA e aprimora a infraestrutura de dados e visualização do sistema.

---

## Requisitos Funcionais

### 1. Isolamento Multi-tenant do Kanban (/board)
- [x] **REQ-1201**: Endpoint `/api/candidate/board` consulta unicamente `user_saved_jobs` filtrado por `session.userId`.
- [x] **REQ-1202**: O Kanban de novos candidatos inicia em zero-state (0 vagas).
- [x] **REQ-1203**: Movimentação via Drag-and-Drop atualiza a coluna `status` de `user_saved_jobs` através de `/api/candidate/board/status`.

### 2. Enforcement do Paywall Free na Análise de CV
- [x] **REQ-1204**: Usuários Free realizam gratuitamente apenas a primeira análise de currículo.
- [x] **REQ-1205**: Tentativas subsequentes de reanálise por usuários Free retornam `HTTP 403 Forbidden`.
- [x] **REQ-1206**: A interface exibe CTA "Upgrade Pro para Reanalisar" redirecionando para a página de planos e preços (`/pricing`).

### 3. Sincronização do Resumo Executivo para a Bio
- [x] **REQ-1207**: Rota `/api/candidate/sync-skills` aceita o campo `summary` no payload.
- [x] **REQ-1208**: O resumo da IA é persistido na coluna `bio` da tabela `candidate_profiles`.
- [x] **REQ-1209**: A aba de perfil do candidato é atualizada em tempo real após a sincronização.

### 4. Scraper Stream & Visual Polishing
- [x] **REQ-1210**: Logs de scrapers transmitem sem atrasos de buffer (`PYTHONUNBUFFERED: '1'`).
- [x] **REQ-1211**: Utilitário de reset de banco para testes de zero-state implementado de forma segura.
- [x] **REQ-1212**: Paridade visual total entre tema claro e escuro no design system.
